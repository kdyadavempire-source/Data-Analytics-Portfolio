# Power BI Dashboard

An interactive Power BI dashboard was designed to analyze sales and revenue performance.

## Dashboard Pages

### 1. Executive Overview
- Total Revenue
- Total Profit
- Total Orders
- Total Quantity
- Average Order Value
- Profit Margin

### 2. Product Analysis
- Top Products
- Product Revenue
- Product Profit
- Quantity Sold

### 3. Regional Analysis
- Revenue by Region
- Profit by Region
- Regional Performance

### 4. Customer Analysis
- Top Customers
- Customer Revenue
- Customer Orders
- Customer Profit

### 5. Trend Analysis
- Monthly Revenue
- Yearly Revenue
- Revenue Growth

## Power BI Features

- KPI Cards
- Bar Charts
- Line Charts
- Donut Charts
- Tables
- Slicers
- Interactive Filters

## Technologies

- Power BI
- Power Query
- DAX
- MySQL
